# Which guide answers the query?

This 84-second director's cut follows an API key search and two guide arrows. The first 26.5 seconds reuse the picture, voice and score from the full Embedding Geometry film. The new passage puts an engraved ruler along the query so viewers can read the projections directly.

The raw horizontal scores are 1 for Rotation and 4 for Audit. Giving both arrows unit length changes their horizontal projections to 0.981 and 0.894. The camera stays parked as the tips move, then moves closer so viewers can read the difference. When the query turns upward, the same two unit arrows project to 0.196 and 0.447. Their marks pass each other at about 18.94 degrees. The full lesson retains distance metrics, vector compression, indexing and shortlist rescoring.

## Build

Give the director-cuts runner the original 096 study master. The film uses its opening and timed English captions. The source in this directory contains the new narration and picture. The course generates new takes and a warm background score with its configured narrator. The program measures the dialogue and times the camera, marks and answer reveals to the words.

The film builder accepts the common DIRECTOR_MASTER, DIRECTOR_OUTPUT, DIRECTOR_WORK and COURSE_VIDEOS environment variables. DIRECTOR_MODULES can select a separate installation containing both Vizmatic and the native canvas package. It must provide the signed source version with the projection and video-render APIs. Run `node build.mjs` from any directory after setting those variables.
