# Component requests

A rebuilt lesson draws a picture from primitives when Vizmatic has no object for it, and adds one line here. The library takes the requests family by family. See `REBUILD.md`, section 11.

One line for each request: the lesson and the scene, what the picture draws, what the object must do, and the file that draws it now. Add a line with one `printf ... >> COMPONENT-REQUESTS.md` command. Do not edit the lines of another lesson.
