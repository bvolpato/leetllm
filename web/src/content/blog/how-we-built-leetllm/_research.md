## The Content Pipeline Architecture

Start with a concrete correction that affects text, a visual, and cached output. The bundle and build pipeline keep those dependencies reviewable, but cannot guarantee that the explanation teaches well.

- **Source Queue:** Papers, documentation, and repositories are editorial inputs. A reviewer must still verify that a selected source supports the published claim.
- **Research Packet:** Extracts claims, tracks freshness dates, identifies learner misconceptions, and defines concrete examples and failure cases.
- **Article Bundle:** A structured directory containing `content.md` with JSON frontmatter, custom illustration TSX files, generated assets, and global reference keys.
- **Validation Checks:** Specific validators check metadata, reference keys, marked Python output, structure, curriculum handoffs, quiz rules, and visual layout. They cannot verify that a citation is current or relevant, or that a blog needs code.
- **Rendered Output:** The final assembly of SEO metadata, cached routes, and interactive components.
