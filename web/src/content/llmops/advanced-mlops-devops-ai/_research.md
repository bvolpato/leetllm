# Manually checked source notes, September 22, 2026

Relevant selections read, not complete upstream projects or every paper. Examples execute local numeric, policy, and SQLite contracts. No model/provider call, feature-store materialization, Kubernetes deployment, hosted-registry update, serving benchmark, or live recovery ran.

- [OpenGitOps principles](https://opengitops.dev/), all four definitions: declarative desired state, versioned/immutable history, automatic pull, and continuous reconciliation attempts. These don't imply that a cluster or external registry is always immediately synchronized.
- [Argo CD automated sync](https://argo-cd.readthedocs.io/en/stable/user-guide/auto_sync/), drift/rollback selections: selfHeal is opt-in; multi-source updates can still trigger reconciliation; automated-sync applications don't support the rollback command. Ordinary rollback repairs desired state; emergency traffic action also needs coordination and a durable repair.
- [MLflow model-registry workflow](https://mlflow.org/docs/latest/ml/model-registry/workflow/), alias-loading/promotion/stage-migration selections: a load resolves the alias's current model version, and another load picks up a reassigned alias. This doesn't replace an already-loaded worker object. Tags and aliases don't themselves implement fleet recovery or an automatic rollback audit.
- [MLflow prompt registry](https://mlflow.org/docs/latest/genai/prompt-registry/), template/config/cache selections: immutable template versions, mutable attached model_config, version/alias caching, configurable TTL, and invalidation operations. A version label alone doesn't freeze all generation configuration or force immediate cross-worker refresh.
- [LangSmith prompt concepts](https://docs.langchain.com/langsmith/prompt-engineering-concepts), template/tool/model/version/dataset selections: commit hashes, movable tags, reserved environment tags, and testing datasets. Semantic versions are an application policy, not a universal prompt-registry requirement.
- [Feast home](https://feast.dev/) and [type system](https://docs.feast.dev/reference/type-system), retrieval/array declarations: offline and online interfaces, declared Array(Float32) values, and data-source schemas. The unexecuted feature-view sketch declares objects; it creates neither the Parquet data nor a materialized online store.
- [Feast point-in-time joins, official source](https://github.com/feast-dev/feast/blob/master/docs/getting-started/concepts/point-in-time-joins.md), full relevant join/TTL/created-time sections: event-time lookback, correction deduplication, filter_by_created_timestamp, exclusion of null created times, and explicit errors for unsupported stores. An availability field must reflect actual online availability before the filtered join reproduces it.
- [Feast online store, official source](https://github.com/feast-dev/feast/blob/master/docs/getting-started/components/online-store.md), complete short page: materialization/push and latest-value storage. Historical joins use a separate interface. Consult version-qualified support rather than extrapolating this general description to every versioning extension.
- [Feast feature retrieval](https://docs.feast.dev/getting-started/concepts/feature-retrieval), interfaces/feature-service/reference/version sections: version-qualified @v<N> online reads require enable_online_feature_view_versioning and currently support only SQLite. Application releases@4/5 labels aren't portable lookup recipes or evidence that another backend retains an old snapshot.
- [Argo Rollouts analysis](https://argoproj.github.io/argo-rollouts/features/analysis/), CRD, inconclusive, NaN/infinity, and empty-result sections: configured success/failure expressions govern continue/abort/pause. Examples intentionally permit or reject NaN/empty data; absence doesn't automatically fail closed. Production conditions must implement the required-data policy.
- [Sato et al., CD4ML](https://martinfowler.com/articles/cd4ml.html), definition/testing/promotion selections: code/model/data changes, reproducible release process, held-out data, slice checks, repeated-set overfitting, and training-serving feature mismatches.
- [Paleyes et al., arXiv record/abstract](https://arxiv.org/abs/2011.09926), authors, 2022 revision, and deployment-workflow framing. Full survey wasn't reviewed. [Sculley et al., original NeurIPS abstract](https://proceedings.neurips.cc/paper/2015/hash/86df7dcfd896fcaf2674f757a2463eba-Abstract.html) supports data dependencies, configuration issues, and hidden feedback/consumers. Google's landing page exposes metadata but an empty abstract; the proceedings abstract supplied the framing, not a review of the full paper.
- [MLflow LLMOps guide](https://mlflow.org/llmops), release/tracing/evaluation/prompt/gateway selections: wider application inputs and sampled evaluation. Its marketing wording that conventional assertions are impossible is too broad; the lesson retains exact checks for structured contracts and treats semantic scoring as task-dependent.
- [Python math](https://docs.python.org/3/library/math.html), hypot selection: n-dimensional Euclidean norm. Rescaling before hypot avoids unrepresentable full norms in the local fixture. This is numerical verification, not embedding-quality evidence.

Original guard probes reproduced NaN age/count acceptance, boolean-rate acceptance, and huge-integer math.isfinite overflow. Original normalization returned an all-zero vector for [1e308, 1e308] and rejected a nonzero [1e-300, 1e-300] after squaring underflowed. Revised contracts reject invalid numeric metadata and rescale before normalization. Added a dot-product ranking exercise; cosine's scale invariance makes normalization mismatch alone insufficient for causality.

An original digest-only SQLite probe let a delayed decision overwrite a redeployed copy of the same artifact. Revised compare-and-swap checks a monotonic routing generation too, binds it to traces/audit, and exercises ordinary stale and repeated-release stale decisions. This is a local concurrency inference and verified SQLite contract, not a claimed MLflow/Argo bug or distributed transaction guarantee. Updated the matching question and replaced generated research claiming guaranteed feature consistency, harmless shadowing, and automatic registry rollback/audit.
