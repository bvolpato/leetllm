# Manual source notes: A/B Testing for LLMs

Reviewed September 23, 2026. This file records source selections and editorial decisions. It is not a generated writing plan. The chapter follows one invented docs-assistant prompt experiment from an offline challenge screen to assigned-unit analysis and an operational hold decision.

## Sources checked for this review

- [Statsmodels two-proportion power](https://www.statsmodels.org/stable/generated/statsmodels.stats.proportion.power_proportions_2indep.html): read the method documentation, including pooled null variance, unpooled alternative variance, allocation ratio, and sidedness. The displayed equal-allocation normal approximation gives 2,942, 8,258, and 18,672 total independent units. These budgets assume the specified effect and design, not every nonzero effect or every critical subgroup.
- [Microsoft pre-experiment guidance](https://www.microsoft.com/en-us/research/articles/patterns-of-trustworthy-experimentation-pre-experiment-stage/): read the article body. Network effects, assignment units, counterfactual logging, pre-period data, and shared caches can change interpretation. A model-plus-prompt bundle is a valid treatment; component attribution requires a different design.
- [Fabijan and colleagues' author-hosted SRM paper](https://exp-platform.com/Documents/2019_KDDFabijanGupchupFuptaOmhoverVermeerDmitriev.pdf): read metadata, abstract, introduction, and experiment-process/background selections. Corrected the shared record to the full title and seven actual authors: Aleksander Fabijan, Jayant Gupchup, Somit Gupta, Jeff Omhover, Wen Qin, Lukas Vermeer, and Pavel Dmitriev. The DOI endpoint was access-blocked; the author-hosted PDF supplies the metadata.
- [Microsoft SRM diagnosis guide](https://www.microsoft.com/en-us/research/articles/diagnosing-sample-ratio-mismatch-in-a-b-testing/): read the article body. SRM is an alarm requiring investigation across assignment, execution, logging, and analysis; it doesn't identify the defect or validate reweighting as a repair. The lesson's two-arm chi-square illustration is not the platform's universal alert policy.
- [Chapelle and colleagues' interleaving paper](https://www.cs.cornell.edu/~tj/publications/chapelle_etal_12a.pdf): checked section 3.2's balanced team-draft mechanism and section 9's identical-prefix/deduped-scoring discussion. The lesson explicitly identifies its neutral-prefix treatment and continue-with-the-remaining-ranker exhaustion behavior as local choices. Algorithm 2 stops when either input is exhausted. Its drafting example is not a full preference estimator or evidence from users.
- [BERTScore author abstract and metadata](https://arxiv.org/abs/1904.09675): contextual token matching compares candidate and reference text. The 2020 ICLR citation is consistent with the revised paper. Similarity doesn't establish factual correctness, current policy, or citation entailment.
- [Statsmodels false-discovery correction](https://www.statsmodels.org/stable/generated/statsmodels.stats.multitest.fdrcorrection.html): checked method assumptions and the reverse monotonic adjustment. BH controls false-discovery rate under appropriate dependence conditions; Bonferroni instead protects a family-wise criterion. Neither turns an exploratory finding into a safety guarantee.
- [Johari and colleagues' always-valid inference abstract](https://arxiv.org/abs/1512.04922): checked the distinction between ordinary fixed-horizon p-values and inference designed for continuous monitoring. This extended manuscript is not a metadata replacement for the chapter's separate KDD 2017 citation. Reused the preceding Experiment Design lesson's inspected sequential-method sources, including [gsDesign spending functions](https://keaven.github.io/gsDesign/reference/sfLDOF.html). The local four-look example uses a computed Bonferroni boundary, not an invented O'Brien-Fleming schedule.
- [Thompson Sampling tutorial abstract and metadata](https://arxiv.org/abs/1707.02038): checked sequential exploration/exploitation scope and the 2018 journal reference. Reused the preceding Experiment Design review's Bernoulli-method selections. The local Beta parameters include one-count priors, and the 500 pulls are synthetic. Ordinary fixed-allocation inference isn't automatically valid after reward-driven allocation.
- [Experiment Guide author website](https://experimentguide.com/): checked book title, authors, and 2020 citation metadata. This is a metadata check, not a new full-book reading.

## Corrections and evidence limits

Removed the generated packet's unsupported divergence percentages, claim that variable LLM outputs break standard A/B testing, blanket prohibition on bundled treatments, mandatory hardest-segment sizing or variance multiplier, universal user-level assignment, fixed rollout percentages, instant rollback guarantee, and mandatory one-to-two-week test floor. Each is a design choice or unsupported claim, not an LLM-specific statistical law.

Corrected reference requirements, the challenge-only golden-set definition, source-free accuracy scoring, human judgments labeled as ground truth, and baseline-only harm limits. Added concrete checkpoint decisions and the distinction between an absolute service violation and a relative treatment regression. Async answer-quality judging must be paired with measured latency/cost/error telemetry; it cannot promise detection of rare failures.

Before editing, reproduced a boolean latency silently passing, string telemetry raising TypeError, and an oversized integer raising OverflowError. The aggregate monitor now treats these as unavailable measurements and returns a pause recommendation. Four malformed windows check that behavior and reset the breach streak. A real controller still needs durable state and action execution; finite telemetry alone doesn't prove adequate window sample size.

Also reproduced a positive MDE rounding away and causing division by zero, and tiny alpha rounding its normal quantile to one. The calculator rejects unsupported precision/range with ValueError; the three ordinary budgets remain unchanged.

All article figures, outcomes, p-values, rubric scores, and bandit rewards are invented or locally calculated. The judge harness only serializes instructions, approved invented evidence, and candidate outputs. No model, live user experiment, safety detector, serving benchmark, or production rollback was run. Relevant source selections were checked; these notes do not claim full-paper or full-project rereads.
