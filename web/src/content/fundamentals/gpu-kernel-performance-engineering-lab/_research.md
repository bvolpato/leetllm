# GPU Kernel Performance Engineering Lab

Manual primary-source refresh: September 22, 2026. Full article, download assets, native illustration, and banner source read individually. No CUDA compilation, execution, profiler collection, or sanitizer run was performed. CPU coordinate models and the actual shared C++ host-checking header were executed independently.

- [CUDA Best Practices 13.4](https://docs.nvidia.com/cuda/cuda-c-best-practices-guide/index.html): compute capability 6.0+ coalescing counts 32-byte sectors. A full aligned float32 warp covers four sectors. Misalignment and partial active warps change coverage. The article's 12.5% naive-store payload fraction is address-model arithmetic, not measured HBM utilization or proof of a DRAM bottleneck. The new exercise explicitly compares aligned, odd-row, strided, and one-lane cases.
- [Nsight Compute memory tables](https://docs.nvidia.com/nsight-compute/ProfilingGuide/): requests, sectors, wavefronts, and downstream bytes are distinct. Use L1/TEX Sectors/Req and target-supported metrics, rather than promising a copied efficiency suffix exists. Shared conflicts are serviced as conflict-free wavefronts; source attribution and aggregate counters can differ. [Compute Triage memory fundamentals](https://docs.nvidia.com/nsight-compute/ComputeTriage/index.html) describe the scalar bank-service model and distinguish cache-stage coverage from later traffic. A one-wavefront bank service isn't a universal load-to-use latency or kernel speedup.
- [Mark Harris's original transpose article](https://developer.nvidia.com/blog/efficient-matrix-transpose-cuda-cc/), February 18, 2013: block 32×8, shared tile 32×32, barrier, and a 33-word padded row demonstrate adjacent global accesses and conflict removal. Its Tesla M2050/K20c performance measurements are historical. No 95%-of-copy promise applies to this download. Copy provides context rather than a guaranteed transpose ceiling.
- [CUDA language extensions](https://docs.nvidia.com/cuda/cuda-programming-guide/05-appendices/cpp-language-extensions.html): small constant-trip loops may already be unrolled. A pragma controls a selected loop without promising a specific SASS instruction order or complete latency overlap. The downloadable starter has no explicit pragmas; body snippets now match it, and the pragma example is a separate experiment. Removed the unsupported sample compiler result and universal DRAM-cycle/register-threshold claims.
- [NVCC 13.4](https://docs.nvidia.com/cuda/cuda-compiler-driver-nvcc/index.html): native targeting detects visible supported GPUs, can emit multiple machine-code targets, and generates no PTX fallback. Compiler resources and spills are actual build observations. Zero spills can be desirable, but cached local-memory traffic doesn't automatically destroy throughput or invalidate correctness.
- [Nsight Compute CLI](https://docs.nvidia.com/nsight-compute/NsightComputeCli/): kernel-name filtering and launch skipping identify the diagnostic launch. Full collection can replay; clean timing remains separate. Repeated CSV now records round and position. Each timing row is a batch mean, not individual latency percentiles or proof of cache residency. A poisoned fresh check after timing doesn't inspect each timed output.
- [Compute Sanitizer](https://docs.nvidia.com/compute-sanitizer/ComputeSanitizer/): memcheck, racecheck, and synccheck have different scopes. Inspect actual shared hazards and application/tool outcomes for the omitted-barrier variant. RAW/WAR ordering depends on the observed schedule. Clean dynamic reports cover exercised paths, not every schedule. Restore the barrier outside the bounds conditions; moving global accesses outside guards is unsafe.
- [Historical reduction material](https://developer.download.nvidia.com/compute/cuda/1.1-Beta/x86_website/projects/reduction/doc/reduction.pdf): tree aggregation is useful background. Its old implicit warp-synchronous code and “no global synchronization” statement aren't current universal CUDA rules. The article uses it only for reduction selection, not a modern implementation. Reductions collapse summaries; scans provide prefix offsets. Declare nonfinite handling and floating-point rounding requirements.

The host checker verifies bit representations, so signed zero differs despite zero absolute error. Input generation uses unique exact integers through N²−1 for N≤4096; this doesn't exercise every float bit pattern. An actual-header C++17 probe checks seven shapes, copy/transpose mapping, poisoned omissions, signed zero, invalid arguments, and shape rejection. Overlap of timing distributions alone doesn't prove equality; the quiz now states that paired evidence hasn't resolved a benefit.
