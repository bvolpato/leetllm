# Manual source review, September 22, 2026

The previous generated packet overstated speed, quality, concurrency, and training guarantees. This note records source boundaries for the individually edited lesson; it is not a generated outline or an automatic review result.

- [Shazeer, MQA (2019)](https://arxiv.org/abs/1911.02150) shares K/V across distinct query heads. Its experimental quality tradeoff does not establish the fastest or best architecture for every workload.
- [Ainslie et al., GQA (2023), methods and results](https://arxiv.org/html/2305.13245v3) mean-pools K/V projections and adapts T5.1.1 with its original pretraining recipe. The tested budget is 5% of original steps. Its mixed task scores are not universal percent-accuracy recovery; GLUE was explicitly excluded.
- [Meta's original Llama 3 card](https://github.com/meta-llama/llama3/blob/main/MODEL_CARD.md) lists 8K context. [The Llama 3 herd paper](https://arxiv.org/html/2407.21783v2) describes the July family with 128K context and eight KV heads at the three published scales. Label the lesson's rows Llama 3.1.
- [Qwen2.5-72B-Instruct](https://huggingface.co/Qwen/Qwen2.5-72B-Instruct) distinguishes its default 32K configuration from extended 128K context with YaRN. [Mistral v0.3's configuration](https://huggingface.co/mistralai/Mistral-7B-v0.3/blob/main/config.json) has 32K positions and no sliding window; the [v0.1 paper](https://arxiv.org/abs/2310.06825) describes sliding-window attention.
- [Gemma 2's report](https://storage.googleapis.com/deepmind-media/gemma/gemma-2-report.pdf) supplies the 9B head counts and alternating local/global layers. [Qwen3.6-27B](https://huggingface.co/Qwen/Qwen3.6-27B) combines sixteen full-attention layers with forty-eight recurrent layers. Sum each architecture's actual state; head width need not equal hidden width divided by query heads.
- [DeepSeek-V2](https://arxiv.org/html/2405.04434v5) describes latent compression, matrix absorption, and decoupled RoPE. [DeepSeek-V3's configuration](https://huggingface.co/deepseek-ai/DeepSeek-V3/blob/main/config.json) uses KV rank 512 and positional width 64. RoPE remains linear and matrix multiplication associative: cached-position rotations make a naively absorbed query position-dependent. The lesson's rotation example demonstrates this distinction.
- [vLLM's Llama implementation](https://github.com/vllm-project/vllm/blob/main/vllm/model_executor/models/llama.py) checks head divisibility and replicates KV heads when TP exceeds their count. Scope these constraints to that layout. Physical aggregate payload can exceed the unreplicated logical payload.
- [FlashAttention's interface](https://github.com/Dao-AILab/flash-attention) documents grouped head mapping and bottom-right non-square causal alignment. [PyTorch SDPA](https://docs.pytorch.org/docs/2.14/generated/torch.nn.functional.scaled_dot_product_attention.html) documents upper-left non-square alignment and backend-dependent dispatch. The runnable latest-query example shows why a causal flag alone does not define correct cached positions.
- [FlashInfer](https://arxiv.org/abs/2501.01005) provides serving attention kernels for different layouts. Reference head expansion can add a large temporary tensor without changing the compact persistent cache. Inspect the selected kernel and allocations.
- [Shipping H100 specifications](https://www.nvidia.com/en-us/data-center/h100/) mark 1,979 BF16 TFLOPS as sparse; [Hopper architecture documentation](https://developer.nvidia.com/blog/nvidia-hopper-architecture-in-depth/) explains the doubling. Dense peak is 989.5 TFLOPS for the specified SXM product. A roofline rate ratio does not measure idle cycles.
- [Pope et al.'s serving study](https://proceedings.mlsys.org/paper_files/paper/2023/hash/c4be8a09197e4ee0f2e55bb16ceea2cd-Abstract-mlsys2023.html) studies TPU serving and partitioning. The lesson's 72B-style cache arithmetic is a worked hypothetical, not a reported result from that paper.

Manual teaching decisions: distinguish raw payload, physical copies, temporary memory, and total service traffic; derive the read-once ideal explicitly; contrast pooling initialization with function preservation; compare cached and recomputed paths within the same model. All CPU examples illustrate arithmetic and index semantics, not measured GPU speedups or pretrained-model quality evaluations.
