# Manually checked source notes, September 22, 2026

Relevant selections inspected, not whole upstream projects or every paper. Examples execute scalar arithmetic, CPU scan/control flow, and declared memory/timing worksheets. No trained model, GPU kernel, engine cache mode, retrieval benchmark, or deployment was run.

- [HiPPO, HTML v1](https://arxiv.org/html/2008.07669v1), abstract and function-approximation setup: optimal polynomial coefficients depend on the specified measure and finite-dimensional subspace. This isn't exact storage of arbitrary history or a retrieval guarantee.
- [S4, HTML v3](https://arxiv.org/html/2111.00396v3), recurrence/convolution and parameterization selections: original bilinear discretization, zero-state convolution, normal/diagonal-plus-low-rank structure, and O(state-size) recurrent update. The lesson's exact ZOH calculation is a distinct discretization illustration; generic dense transitions don't inherit S4's costs.
- [Mamba-1, HTML v2](https://arxiv.org/html/2312.00752v2), selection/scan/discretization and E.5 selections: input-dependent B/C/Delta, input-independent transition, associative scan, and fusion/recomputation. Throughput uses A100 80GB PCIe, 2048-token prompts, 128-token generations, batch 1–128, and three-repetition means. Compared 1.4B/untrained 6.9B Mamba against standard Hugging Face GPT-3-style 1.3B/6.7B Transformers; larger feasible batches contribute to reported 4–5× throughput. No matched-quality modern-engine guarantee. The paper's ZOH gating example doesn't replace the actual implementation's input term.
- [Pinned selective-scan reference](https://github.com/state-spaces/mamba/blob/e9594ce1c732d97440f0332fdc43170a2294dbfa/mamba_ssm/ops/selective_scan_interface.py), reference function selections retrieved directly: exp(delta*A), delta*B*u, readout, skip, and output gate. [Pinned Mamba-1 block](https://github.com/state-spaces/mamba/blob/e9594ce1c732d97440f0332fdc43170a2294dbfa/mamba_ssm/modules/mamba_simple.py), forward/step/cache sections: post-convolution selective maps, negative transition, in-place updates, full convolution-width buffer, dtype choices, and initialization. Both source files were fetched at the inspected commit; no optimized kernel executed.
- [Mamba-2, HTML v1](https://arxiv.org/html/2405.21060v1), SSD overview/block decomposition/speed sections: scalar-times-identity within heads; structured masked attention without arbitrary softmax equivalence; diagonal chunk outputs, chunk states, inter-chunk propagation, and output contributions. Boundary propagation may use a scan or 1-SS multiplication; the minimal listing uses structured matrix multiplication. The 2–8× efficiency figure uses state expansion 64; end-to-end speed and separate language-model evaluations must not be conflated.
- [Mamba-3, HTML v1](https://arxiv.org/html/2603.15569v1), recurrence/architecture/quality/latency selections: exponential-trapezoidal update with previous write, second-order condition lambda=1/2+O(Delta), data-dependent rotations, parameter-matched MIMO, and removed external short convolution. 1.5B models trained on 100B FineWeb-Edu tokens with 2K context underpin the cited accuracy comparison; separate 440M state-size sweeps underpin the perplexity/state trade-off. Single-step latency compares FP32/BF16 at batch 128 on one H100 with state sizes 64/128. Up to fourfold more decode FLOPs at similar latency isn't fourfold tokens/s or a 32K retrieval certificate. The scalar discretization comparison omits complex/MIMO operations.
- [Original Jamba, HTML v1](https://arxiv.org/html/2403.19887v1), architecture and configuration selections: four eight-layer blocks, attention:Mamba 1:7, alternate-layer MoE, 16/top-two experts. Single-80GB-GPU int8 findings are historical configuration-specific evidence, not a guarantee of 256K on an unspecified device.
- [Nemotron-H, HTML v2](https://arxiv.org/html/2504.03624v2), architecture sections: 8B model has four attention, 24 Mamba-2, and 24 FFN separately counted sublayers; first Mamba, last FFN, attention precedes FFN. These conventions differ from Jamba's mixer-plus-MLP layers.
- [Qwen3.6-35B-A3B card](https://huggingface.co/Qwen/Qwen3.6-35B-A3B), architecture list inspected in preceding MoE bundle on the same date: ten groups of three Gated DeltaNet layers then gated attention, each with MoE. Delta-rule linear attention isn't the same recurrence as Mamba.
- [Pinned vLLM cache configuration](https://github.com/vllm-project/vllm/blob/4edb55169f69c76bb87ab9f154585917cb01bb17/vllm/config/cache.py), cache/dtype/replay declarations: none/all/align strategies, separate SSM dtype, shared-prefix checkpoints, and restricted replay paths. [Official APC source guide](https://github.com/vllm-project/vllm/blob/main/docs/features/automatic_prefix_caching.md), current hybrid section retrieved/read: checkpoint boundaries and speculative/model constraints. An older [hybrid design page](https://docs.vllm.ai/en/latest/design/hybrid_kv_cache_manager/) still calls Mamba prefix caching work in progress, so it isn't used to claim current blanket unavailability. No serving flags executed.

Reproduced boolean-step acceptance, huge-integer conversion overflow, exponential overflow from finite inputs, and infinite coefficients from a finite input write in the original ZOH helper. Revised finite checks also handle a zero interval and an underflowed delta*A product. The scalar collision proves only that example's indistinguishable histories.
