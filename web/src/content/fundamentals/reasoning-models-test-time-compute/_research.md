# Manually checked source notes, September 22, 2026

Relevant selections read, not whole upstream projects or every paper. Examples are scalar probability/cache/cost worksheets and scripted search. No provider call, language-model inference, trained scorer, GPU benchmark, or deployed routing evaluation ran.

- [Kaplan et al., HTML v1](https://arxiv.org/html/2001.08361v1), notation and compute-accounting selections: non-embedding parameters, approximately 6N forward/backward FLOPs per processed training token, attention-term assumptions, and empirical loss fits. The worksheet's D counts repeated processing, rather than unique corpus size. A stored MoE parameter count doesn't directly give executed FLOPs.
- [Snell et al., HTML v1](https://arxiv.org/html/2408.03314v1), setup/difficulty/search/aggregation/FLOPs-exchange selections: PaLM 2-S* on MATH; difficulty-bin policies; difficulty-estimation compute omitted from the study comparison; rollout-trained reward-to-go PRM; last-step aggregation beats minimum/product in this experiment; verifier exploitation/over-optimization. The roughly 14-times-larger comparison exchanges total pretraining plus expected inference FLOPs and depends on lifetime inference load. This doesn't certify equal request latency or current serving cost. The lesson's minimum-score beam is a separate teaching heuristic.
- [Wei et al., HTML v6](https://arxiv.org/html/2201.11903v6), abstract and method framing: few-shot chain-of-thought demonstrations elicit intermediate steps without changing weights. This differs from reasoning-oriented post-training; it isn't universal advice to expose raw thinking on current hosted models.
- [OpenAI's o1 launch post](https://openai.com/index/learning-to-reason-with-llms/), dated September 12, 2024, AIME selections: single sample, consensus over 64, and learned reranking over 1000 are different evaluated policies. Historical results aren't model-independent scaling guarantees.
- [DeepSeek-R1, HTML v1](https://arxiv.org/html/2501.12948v1), training/reward/distillation/evaluation selections: pretrained V3-Base, RL-only R1-Zero post-training, R1's cold start, language-consistency reward, filtered reasoning plus general data, second SFT restarted from V3-Base, and final rule-based/preference reward split. Updated the diagram to distinguish generated training data from continuing weights. Original AIME distillation figures and temperature 0.6/top-p 0.95 pass@1 estimation remain historical paper results.
- [OpenAI reasoning guide](https://developers.openai.com/api/docs/guides/reasoning), current effort/accounting/cutoff/persistence selections: model-dependent effort values; reasoning included in output usage; total-generated-token cap includes reasoning and non-visible formatting; incomplete output can be empty and still billed. GPT-5.6 defaults to available compatible earlier reasoning with all_turns; previous response items must be available and cross-family compatibility isn't automatic. Inspected the repository's local usage adapter first; it isn't an API reference or live provider test.
- [Gemini thinking guide](https://ai.google.dev/gemini-api/docs/thinking), current Interactions selections: generation_config.thinking_level, supported values by model, max_output_tokens hard cutoff including thoughts, incomplete/empty output, separate total_thought_tokens plus total_output_tokens pricing, and stored/stateless thought-signature continuity. No generateContent recipe or interchangeable field/accounting formula is inferred.
- [Claude extended-thinking guide](https://platform.claude.com/docs/en/build-with-claude/extended-thinking), current manual/adaptive/migration selections: manual budget_tokens deprecated on 4.6 and rejected on 4.7/later; adaptive mode uses effort, with max_tokens as a response cutoff. Support and defaults remain model-specific. This doesn't mean every older model supports adaptive thinking.
- [Lightman et al., HTML v1](https://arxiv.org/html/2305.20050v1), supervision/method selections: human positive/negative/neutral intermediate labels, MATH process-versus-outcome evaluation, and separate generator/reward models. A learned step score is not a proof.
- [Math-Shepherd, HTML v1](https://arxiv.org/html/2312.08935v1) and [current v3](https://arxiv.org/html/2312.08935v3), automatic-label target selections: completion outcomes determine hard any-success and soft success-frequency labels. These measure potential under the completer, rather than direct human validity judgments. The lesson's incorrect arithmetic step with later repaired completions is a declared counterexample, not a recorded model trajectory.
- [Chen et al., NeurIPS 2025 abstract](https://proceedings.neurips.cc/paper_files/paper/2025/hash/e8f4eae0a41cab67fdead3aa6b77f083-Abstract-Conference.html): CE can misalign with pass@N in MATH/MiniF2F and confidence-limiting training improves their tested search settings. The two-prompt example is illustrative, not evidence of an actual CE run.
- [Ghosal et al., HTML v3](https://arxiv.org/html/2506.04210v3), intervention/model/benchmark selections: forced Wait insertions and delimiter suppression, three R1-distilled models, GSM8K/MATH-500/AIME 2024, non-monotonic or declining quality, variance analysis, and parallel-thinking comparisons. These aren't a universal curve for natural provider effort controls. Verified the arXiv record and corrected Avinash Reddy's initial; a search snippet returned an inconsistent title, so the actual record governs.
- [Anthropic Fellows inverse-scaling study](https://alignment.anthropic.com/2025/inverse-scaling/), setup and examples: constructed distraction/constraint tasks demonstrate possible harm from extra reasoning. These observations aren't unconditional statements about every task or model.
- [Setlur et al., HTML v1](https://arxiv.org/html/2502.12118v1), abstract/problem assumptions/anti-concentration selections: heterogeneous correct traces and reward-distribution assumptions support verifier-based versus trace-cloning separation as data and budget grow. This isn't a universal impossibility theorem for distillation. Proof appendices weren't reviewed in full.
