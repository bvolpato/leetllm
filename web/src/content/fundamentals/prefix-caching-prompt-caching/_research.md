# Manual source notes, September 22, 2026

Scope: complete article bundle read directly. Relevant primary passages checked; no hosted API, GPU benchmark, tenant-isolation experiment, or complete upstream repository audit performed.

- [vLLM prefix design](https://docs.vllm.ai/en/stable/design/prefix_caching/) and its current Markdown source distinguish chained full-block hashes from radix trees. Keys include history and relevant extras. `sha256` is the documented default; CBOR is a serialization option. Released cached blocks can join the free queue without losing content until replacement. Model compatibility is also an engine namespace concern.
- [SGLang paper, section 3](https://arxiv.org/html/2312.07104) describes a compressed prefix tree, reference-aware leaf eviction, and cache-aware scheduling. Its original token granularity and scheduling aren't universal current backend or distributed-router contracts.
- [OpenAI prompt caching](https://developers.openai.com/api/docs/guides/prompt-caching) now lists earlier-message/developer lookup fallbacks, while a later gotcha still describes a latest-message-only miss. The article records this inconsistency and teaches explicit write control without inventing a guaranteed implicit miss. Current marker syntax and Responses usage names checked.
- [OpenAI diagnostics](https://developers.openai.com/api/docs/guides/prompt-caching/diagnostics) says comparison does not load earlier content or change caching behavior. Diagnostics are best effort; usage measures credited reuse. A changed accounting key can produce a reported miss without a physical miss. Its live documentation example uses `gpt-6-astra`.
- [OpenAI pricing](https://developers.openai.com/api/docs/pricing) and [Claude pricing](https://platform.claude.com/docs/en/about-claude/pricing) checked for write/read multipliers. Rates are model-specific; Fable/Mythos 5.1 are exceptions to Claude's usual read multiplier. The break-even fixture assumes complete reuse and one write before expiry.
- [Claude prompt caching](https://platform.claude.com/docs/en/build-with-claude/prompt-caching) checked for minimums, lookup, usage, concurrent availability, and platform isolation. Current minimums span 512–4,096 tokens. Bedrock has its own AWS contract. Workspace isolation isn't universal across platforms.

All timing and block-pool examples are authored CPU fixtures. Token reuse isn't FLOPs saved. The scope-key fixture checks supplied inputs; a separate forged-label exercise models a gateway enforcing a trusted authentication result. Neither proves cryptographic collision impossibility or provider security. Updated visuals remove invented watermarks, benchmark-looking timings, and the false claim that decode performance never changes.
