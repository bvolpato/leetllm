# Manual evidence notes, September 22, 2026

Read the original article, metadata, code, nine quiz questions, four illustration sources, and banner manually. These notes replace generated claims about required architectures, invented latency/token ranges, outdated provider schemas, and benchmark grading. No delegated review or automated authoring was used.

- [Claude computer use](https://platform.claude.com/docs/en/agents-and-tools/tool-use/computer-use-tool) confirms computer_toolset_20260801, client execution, ordered batches, results for every member, full-screenshot coordinates after zoom, current compatibility, and earlier beta contracts. Classifier steering isn't application permission. The article links the complete action/configuration tables rather than copying a brittle exhaustive schema.
- [Claude browser use](https://platform.claude.com/docs/en/agents-and-tools/tool-use/browser-use-tool) supplies a distinct browser_toolset_20260801, tab-scoped host-owned reference maps, structural reads, screenshots, and stale-reference handling. Layout movement isn't necessarily reference invalidation; hidden page text, network defaults, and optional tools need explicit executor policy.
- [OpenAI computer use](https://developers.openai.com/api/docs/guides/tools-computer-use) now recommends client-owned generated-code execution, with the structured computer tool as an alternative. Ordered computer_call actions return a matched computer_call_output screenshot. Generated-call completion isn't execution; conversation continuation doesn't recreate lost runtime state. Arbitrary code can't be governed merely by classifying click labels. Typing sensitive data can already transmit it.
- [Gemini computer use](https://ai.google.dev/gemini-api/docs/computer-use) uses current Interactions examples and distinguishes 3.x browser/desktop/mobile contracts from legacy 2.5. Current action tables specify integers 0–999 on a 1000-unit scale. Screenshot injection detection is opt-in, default false; require_confirmation and acknowledgement require actual host handling even with overrides. Removed the implication that 1000 is a valid point to clamp silently.
- [Playwright mouse](https://playwright.dev/docs/api/class-mouse) uses main-frame viewport CSS pixels. [Page API](https://playwright.dev/docs/api/class-page) distinguishes CSS/device screenshot scales, offers file-input/chooser paths, and discourages networkidle as a readiness assertion. DPR conversion doesn't remove desktop chrome, full-page scroll, or crop offsets. Raw mouse clicks don't inherit locator target checks.
- [Playwright actionability](https://playwright.dev/docs/actionability) checks locator uniqueness, visibility, stability, event reception, and enabled state for normal clicks. The force option can bypass checks; these aren't authorization or complete absence-of-race guarantees.
- [Set-of-Mark paper](https://arxiv.org/html/2310.11441v2) labels visual regions using marks, masks, and boxes. Its original tasks aren't a universal GUI executor. Selecting a mark still requires correct/stable region mapping and geometry. Removed mandatory preprocessing latency and guaranteed elimination of spatial errors.
- [Chrome headless documentation](https://developer.chrome.com/docs/automation-and-testing/headless) confirms unified current headless/headful code and a separate old headless shell. Removed a universal headful-Xvfb production standard, detection equivalence, and identical-rendering guarantee.
- [Xserver manual](https://xorg.freedesktop.org/archive/X11R7.5/doc/man/man1/Xserver.1.html) explains -ac disables access control and -auth supplies a file. [x11vnc options](https://github.com/LibVNC/x11vnc/blob/master/doc/OPTIONS.md) document server-side view-only input rejection, local binding, and authentication. [websockify](https://github.com/novnc/websockify) documents explicit authentication/TLS configuration. The illustrative shell sketch requires precreated secrets, isolated runtime, and supervision; no display/viewing service or browser was launched.
- [Original WebArena repository](https://github.com/web-arena-x/webarena) supplies self-hosted environments and 812 task configurations. [WebArena-Verified](https://github.com/ServiceNow/webarena-verified) documents 812 full tasks, 258 Hard tasks, response/network-trace evaluators, and offline replay. It isn't exclusively a live-database oracle or a July 2026 first release.
- [Original OSWorld](https://arxiv.org/abs/2404.07972) covers real computer tasks; platform support isn't equal task coverage. [OSWorld 2.0 method](https://arxiv.org/html/2606.29537v1) introduces 108 long workflows with weighted checkpoint partial credit and limited model judging. [Current releases](https://github.com/xlang-ai/OSWorld-V2/releases) and [repository](https://github.com/xlang-ai/OSWorld-V2) document September 16 osworld-v2.1 and matching component pins. Removed binary-only grading claims from the old generated packet and avoided unverified live leaderboard scores.
- [Mind2Web](https://arxiv.org/html/2306.06070v3) reports 2,350 retained demonstration tasks from 137 websites and 31 domains; offline action metrics aren't present-day live task success. [GAIA](https://arxiv.org/abs/2311.12983) is answer-oriented general-assistant evaluation. [AgentDojo](https://arxiv.org/abs/2406.13352) measures tool-agent prompt-injection behavior, not GUI pointing accuracy.

The revised delayed-effect fixture distinguishes not-dispatched, verified, and unknown outcomes. An unchanged screenshot isn't evidence that a server didn't queue a mutation; blind replay can duplicate notes. Other labs use local dataclasses, strings, and a Python portal, not real credentials, browsers, models, or application permissions. Approval objects assume trusted provenance; sequential in-memory replay tracking isn't durable, atomic, actor-scoped production approval storage.

The inspection pilot ends at a local draft. Posting, notifying a team, or rerunning a job needs separately scoped authority and applicable confirmation. Domain allowlists don't certify read-only effects or prevent transmission to an allowed service; observable audit coverage doesn't establish absence of every side effect. Four revised figures teach the observation loop, numeric crop transform, task-slice routing, and pre/post-dispatch evidence without universal timings or an unbypassable sandbox claim.
