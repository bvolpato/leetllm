# Multi-agent orchestration: manual source notes

Checked September 22, 2026. Replaces the generated outline's deprecated Assistants/Swarm recommendations, legacy AutoGen classes presented as current, and blanket reliability/approval claims.

- [Cognition's 2025 argument](https://cognition.com/blog/dont-build-multi-agents) concerns lost context and implicit conflicting decisions. [Its 2026 follow-up](https://cognition.com/blog/multi-agents-working) reports useful map-reduce-and-manage patterns and single-threaded writes. These are attributed engineering observations, not a universal prohibition on coordinated concurrent writers.
- [Anthropic's 2025 Research report](https://www.anthropic.com/engineering/multi-agent-research-system) reports a 90.2% relative internal-eval improvement for the named Opus 4/Sonnet 4 setup and approximately fifteen times chat token usage. Neither statistic is a universal multi-agent gain or a multi-agent-versus-single-agent cost ratio.
- [LangGraph runtime](https://docs.langchain.com/oss/python/langgraph/pregel) describes plan, execution, and update phases. Returned channel updates appear in the next superstep. It doesn't establish deep immutability or malicious-code isolation. [Graph API](https://docs.langchain.com/oss/python/langgraph/graph-api) describes state schemas and default replacement/custom reducers; types alone don't grant write ownership.
- [Use the graph API](https://docs.langchain.com/oss/python/langgraph/use-graph-api) distinguishes list-form joins from separate edges, documents skipped-predecessor non-execution, and describes defer=True waiting for graph-wide pending tasks. The fixture tests unequal branch depths and a deliberately unselected health branch, not network timing.
- [Checkpointers](https://docs.langchain.com/oss/python/langgraph/checkpointers) distinguishes superstep snapshots, per-task pending writes, and sync/async/exit durability modes. [Interrupts](https://docs.langchain.com/oss/python/langgraph/interrupts) restart the interrupted node. InMemorySaver supports a live-process pause, not recovery after process loss; moving an effect after interrupt doesn't supply exactly-once external effects.
- [Official PyPI metadata](https://pypi.org/project/langgraph/1.2.12/) confirms 1.2.12 was released September 21. The CPU exercises pin that version; no provider calls or real deployment are involved.
- [Python MappingProxyType](https://docs.python.org/3/library/types.html#types.MappingProxyType) is a read-only dynamic mapping view, not a recursive freeze. The runnable nested-list exercise shows the distinction from copying these values. Neither is a security sandbox.
- [AutoGen's repository](https://github.com/microsoft/autogen) now states maintenance mode, community management, and successor guidance. [GraphFlow docs](https://microsoft.github.io/autogen/stable/user-guide/agentchat-user-guide/graph-flow.html) still mark it experimental. [Microsoft's migration guide](https://learn.microsoft.com/en-us/agent-framework/migration-guide/from-autogen/) contrasts GraphFlow broadcasts with Workflow typed data flow and notes embedded/distributed AutoGen runtimes. Relevant sections inspected, not every SDK path or a migration execution.
- [OpenAI Swarm](https://github.com/openai/swarm) is replaced by the [Agents SDK](https://github.com/openai/openai-agents-python). [SDK handoffs](https://openai.github.io/openai-agents-python/handoffs/) distinguish control transfer, history filtering, and input_type arguments. is_enabled can't authorize parsed arguments before they exist; argument-specific denial must raise in on_handoff. Function-tool input guardrails don't apply to handoffs. The article's wiring is illustrative, not executed.
- [MCP's July 28 release](https://blog.modelcontextprotocol.io/posts/2026-07-28/) confirms a stateless core and Tasks extension. Stateless protocol calls don't force the server application to be stateless, and extension support isn't automatic in every client.
- [A2A specification](https://a2a-protocol.org/latest/specification/) allows direct Message responses or tracked Tasks. Tasks have submitted/working/interrupted/terminal states; polling, streaming, and push are distinct modes with capability/configuration requirements. Its delivery and authentication controls don't certify artifact truth, production authority, or indefinite storage retention.
