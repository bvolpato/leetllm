# Manual evidence notes, September 22, 2026

Read the complete article, metadata, examples, ten quiz questions, two native illustration sources, and banner manually. Replace generated leaderboard/tool-superiority claims and the incorrect audit account with source-specific evidence. No subagent, automated rewrite, or model-review script was used.

- [Copilot cloud agent](https://docs.github.com/en/copilot/concepts/agents/cloud-agent/about-cloud-agent) supports repository research, planning, branch edits, tests in an ephemeral Actions-powered environment, and entry-point-dependent PR creation. [Claude Code overview](https://code.claude.com/docs/en/overview) identifies terminal, IDE, desktop, and web surfaces. Neither product label establishes the permissions of a particular runner.
- [SWE-agent](https://arxiv.org/abs/2405.15793) investigates ACI design and repository navigation/editing/execution. It doesn't establish a universal five-phase lifecycle, mandatory replacement API, context-token count, search latency, or success guarantee.
- [Git worktree](https://git-scm.com/docs/git-worktree) documents private index/HEAD and shared objects, refs, and default configuration. Worktrees reduce checkout collisions, not arbitrary filesystem access or all shared Git-state races. [Git write-tree](https://git-scm.com/docs/git-write-tree) writes the index, not a dirty working snapshot. The new temporary-repository exercise demonstrates unchanged index identity despite edited source and an untracked input, without making a commit.
- [Vitest passWithNoTests](https://vitest.dev/config/passwithnotests) defaults to false. The actual local Vitest 4.1.11 empty-selector probe returned exit 1 and reported no test files. Exit-zero collection behavior is configuration/runner dependent; relevant collected and executed tests still need inspection.
- [pnpm run](https://pnpm.io/cli/run) executes a manifest-defined script. Named commands can run project code and children; fixed argv doesn't constrain their effects. [Docker networking](https://docs.docker.com/engine/network/) describes outbound connectivity and different network drivers. Process isolation/network namespaces alone aren't outbound-deny policy.
- [GitHub protected branches](https://docs.github.com/en/repositories/configuring-branches-and-merges-in-your-repository/managing-protected-branches/about-protected-branches) distinguishes configurable reviews/checks, default bypass behavior, latest-push review requirements, and merge queues. Human-only merge authority is this lesson's organizational policy, not a universal platform capability limit.
- [MCP introduction](https://www.anthropic.com/news/model-context-protocol) describes client/server connections to data/tools. [Current security guidance](https://modelcontextprotocol.io/docs/2026-07-28/tutorials/security/security_best_practices) covers confused-deputy attacks, token audiences, and sandboxing of command-spawning proxies. A protocol/resource connection doesn't confer task authorization.
- [SWE-bench](https://arxiv.org/abs/2310.06770) derives tasks from real issues and corresponding PRs. [SWE-Bench Pro](https://arxiv.org/abs/2509.16941) distinguishes public, held-out, and commercial sets. Correct its citation to Deng, Da, et al.; don't invent current leaderboard winners or claim contamination immunity.
- [OpenAI's February 23 audit](https://openai.com/index/why-we-no-longer-evaluate-swe-bench-verified/) reviewed 138 problems selected because o3 didn't consistently solve them. Its Verified reporting decision isn't a July audit of 731 tasks, a random full-suite estimate, or proof that Pro is contamination-free.
- [ReAct](https://arxiv.org/abs/2210.03629) interleaves reasoning, actions, and observations. [Reflexion](https://arxiv.org/abs/2303.11366) maintains reflection in episodic memory for later trials. A role label or repeated model pass doesn't itself establish independent verification.

The Python worked examples model an AST import-call PageRank graph (`ast`), an isolated `git worktree` snapshot compared with `git write-tree`, a finite-budget generate-test-repair state machine over structured pytest tracebacks, and the unbiased `pass@k` estimator from Codex (`Chen et al., 2021`). All examples use self-contained in-memory fixtures and temporary directories; no external coding-agent service, hosted CI runner, remote repository mutation, or leaderboard evaluation was executed.
