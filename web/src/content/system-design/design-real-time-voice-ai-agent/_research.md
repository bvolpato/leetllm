## Corrections and teaching decisions

- The formatter previously reported “still open” for a supplied closed incident. It now reads the status, rejects unknown values, and asserts the closed case. Its caller still needs an authorized, current result; the formatter cannot enforce authorization or deliver a text message.
- JSON `false` and the string `"false"` are different. Reproduced the original string enabling committed history and speech. Transcript-final and commit flags now require actual booleans; the malformed fixture reports an error. This type check cannot establish who is authorized to commit a turn.
- A float character offset such as `16.0` passed equality-based alignment checks, then failed string slicing. The interruption fixture now requires integer offsets/times and exercises the float rejection. Its character/audio map is an invented application contract, not provider-generated word alignment.
- Visual inspection found an ACK marker at the arbitrary 260ms midpoint of the acknowledged band, despite the 520ms cursor. Moved the markers to the actual 520ms boundary; the chart no longer implies a different acknowledgement time.
- Silence/padding frame counts use exact integer ceiling division. A 61ms threshold with 20ms frames needs four frames. The toy probability frames are not Silero's inference API or window requirements.
- Local speech onset and server turn completion are different events. The VAD diagram now logs typed decisions; compare equivalent boundaries before calling a timing difference disagreement. Local detection can mute without a round trip while server endpointing commits the user's turn.
- The first overlapping clause is an honest acknowledgement, not an incident finding before the lookup returns. A paging-service acceptance is still distinct from a human acknowledging a page. Cancellation of speech or a tool proposal cannot undo an executed side effect.
- Added mono PCM accounting: 20ms at 16kHz is 320 samples/640 bytes; at 24kHz it is 480 samples/960 bytes. Playing the latter as 16kHz takes 30ms. MIME metadata describes samples; it doesn't perform resampling. Replaced a generic architecture quiz question with this concrete mistake.
- AudioPaLM's semantic positions and its downstream acoustic codec tokens are distinct. Compression alone doesn't prove tone preservation. Provider packets and API billing units aren't the research model's 25Hz semantic positions.
- Qualified WebSocket transport to the compared TCP path; HTTP/3 WebSocket exists. A reliable ordered audio stream still has a different delivery contract from deadline-aware RTP over UDP. Loss concealment and adaptive buffers trade fidelity/delay rather than making loss invisible.
- Updated OpenAI cache teaching: matching prefixes also need a usable written endpoint. The current GPT-5.6-and-later guide requires breakpoint-aware reasoning and separate cache-write accounting. Changed the quiz accordingly. These Responses API rules are not automatically Realtime session rules.
- Clarified Gemini's interruption history: retaining output sent to a client isn't proof of playback. Current model-specific tool modes differ; process all output parts and applicable control fields. Updated the Preview attribution to the capabilities guide and the Silero citation year to its README's recommended 2024 entry.

## Primary selections checked

- [OpenAI Realtime client events](https://developers.openai.com/api/reference/resources/realtime/client-events): `conversation.item.truncate` assistant item, current `content_index=0`, millisecond endpoint, errors/acknowledgement, and server transcript deletion. Read the transcription guidance as well: auxiliary transcription needn't equal what the audio model perceived. The local alignment simulation doesn't reproduce server internals.
- [OpenAI's August 28, 2025 Realtime announcement](https://openai.com/index/introducing-gpt-realtime/): production speech-to-speech disclosure and historical release context. No current price or model benchmark is inferred from that announcement.
- [OpenAI prompt caching](https://developers.openai.com/api/docs/guides/prompt-caching): read explicit/implicit writes and lookup boundaries, minimum eligible length, volatile-suffix miss example, usage categories, write/read cost, and migration selections. A cache key cannot create an unwritten shorter-prefix entry. This was checked after finding no local provider implementation to establish a different contract.
- [Gemini Live overview](https://ai.google.dev/gemini-api/docs/live-api): complete overview, updated September 15, 2026; stateful WebSocket, native audio, tools, and ephemeral-token browser guidance. Native input is 16kHz, output 24kHz, signed 16-bit little-endian PCM.
- [Gemini Live capabilities](https://ai.google.dev/gemini-api/docs/live-api/capabilities): model/tool-mode table, multipart output, audio format/resampling, interruption history/tool-call cancellation, and VAD selections. The guide still labels Live Preview. It documents nonblocking support/default for Gemini 3.8 Live and sequential calls for Gemini 3.1 Flash Live Preview; don't treat all Live models as one scheduling contract.
- [LiveKit turn detection](https://livekit.com/blog/turn-detection-voice-agents-vad-endpointing-model-based-detection): read acoustic VAD, endpointing, semantic-turn boundaries, and cutoff tradeoffs. This is Jesse Hall's February 21, 2026 article; the lesson's timings remain hypothetical, not LiveKit benchmark results.
- [W3C media capture](https://w3c.github.io/mediacapture-main/): constraints, supported settings/capabilities, echo-cancellation choices, and ideal-versus-required behavior. Requesting cancellation doesn't establish its effectiveness on a device; inspect actual settings and test double-talk.
- [WebRTC NetEQ](https://webrtc.googlesource.com/src/+/refs/heads/main/modules/audio_coding/neteq/g3doc/index.md): complete implementation overview; adaptive delay, concealment, acceleration/deceleration, comfort noise, and decoder interaction. Its 10ms output API isn't the article's synthetic 20ms transport fixture.
- [Silero VAD README](https://github.com/snakers4/silero-vad): complete current README including supported rates, performance caveats, and recommended citation. The 2024 citation year isn't a claim that VAD was first released in 2024.
- [AudioPaLM](https://arxiv.org/html/2306.12925v1): abstract/metadata and sections 3.1–3.3. Semantic-token quantization, extended text/audio embeddings, separate SoundStream acoustic reconstruction, and voice conditioning. [SpeechGPT](https://arxiv.org/abs/2305.11000): complete abstract/metadata and discrete-speech instruction-training claim. Neither is a current hosted API contract.
- [RTP for WebRTC, RFC 8834](https://www.rfc-editor.org/rfc/rfc8834.html): introduction/security profile and NACK/FEC recovery selections. [WebRTC transports, RFC 8835](https://www.rfc-editor.org/rfc/rfc8835.html): ICE/UDP preference, relay/TCP/TLS alternatives, and mandatory DTLS-SRTP. No claim that every selected path has identical loss behavior.
- [HTTP/3 WebSocket, RFC 9220](https://www.rfc-editor.org/info/rfc9220/): complete RFC information page, including the single-HTTP/3-stream mapping. [QUIC, RFC 9000](https://www.rfc-editor.org/rfc/rfc9000.html): ordered bytes within a stream. Applying those two contracts to an ordered audio stream is an inference, not a measured latency result.
- [AWS idempotent APIs](https://aws.amazon.com/builders-library/making-retries-safe-with-idempotent-APIs/): caller/request identity, argument-intent validation, and atomic mutation selections. Retrying a page safely requires a service operation record, not a transcript edit.
- [Stivers et al., 2009](https://pmc.ncbi.nlm.nih.gov/articles/PMC2705608/): the primary indexed result supports the roughly 208ms mean across the ten-language study. Direct full-text access was blocked by a verification page/403; don't record a fresh full-paper read. It doesn't establish a universal 500ms AI product threshold. Reused previously reviewed stable Whisper, PagedAttention, and speculative-decoding mechanisms.

## Verification and limits

All twelve CPU outputs match, including flag/offset/status regression assertions and PCM arithmetic. Fresh native and Mermaid builds are inspected in both themes. Schema, quiz/navigation/citation integrity, strict visual checks, types, changed-source lint, and focused tests validate the bundle's executable/content contracts. They don't establish factual completeness by themselves.

No microphone capture, ASR/TTS/model inference, WebRTC connection, device echo test, live provider session, resampler, cache write/hit, tool execution, telephony integration, GPU/network benchmark, or deployment was performed. The 380ms trace and capacity numbers are worked synthetic examples; measure actual devices, carriers, codecs, loss slices, interruption tails, and authorization/execution independently.
