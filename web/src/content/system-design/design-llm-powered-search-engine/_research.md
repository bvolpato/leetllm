# LLM-Powered Search Engine: manual source notes

Reviewed September 23, 2026. The complete article bundle was read manually, including metadata, eight executable cells, ten questions, seventeen original reference records, five native sources, the legacy banner prompt, and the previous 83-line generated research packet. These notes replace that packet's unsupported deployment recipes. They are editorial evidence, not an article generator.

## Publication counterexamples

- The original publisher accepted a shorter exact exception quotation that omitted “only with security approval.” Its source ID, revision, whole-document hash, and span still matched. Reproduced locally before editing. The fixed fixture requires exactly one complete quotation from each of its two known single-passage documents. General systems need semantic support and coverage checks for narrower spans; exact quotation alone doesn't establish them.
- The original reducer published when `accepted` was the string `"false"`, and accepted a floating-point revision equal to its integer revision. Reproduced locally. Exact boolean and nonnegative integer validation now keeps malformed decisions pending. This validates representation, not sender authority or claim truth.
- [WHATWG SSE](https://html.spec.whatwg.org/multipage/server-sent-events.html): read the interface/constructor and relevant parsing, dispatch, reconnect, and event-ID selections. An event without `id` inherits the previous last event ID. Added a concrete two-event example and question. Explicit replay identities belong to the application protocol; SSE supplies neither authorization nor exactly-once publication. The native constructor takes a URL and credentials option, not an arbitrary POST body/custom-header interface.

## Retrieval and evidence boundaries

- [Qdrant filtering](https://qdrant.tech/documentation/search/filtering/): relevant filtering/index guidance checked. Eligibility must constrain retrieval before its candidate limit; filtering already selected forbidden top hits can leave the useful result empty. This isn't a claim that payload filters establish a complete authorization system.
- [Elastic document-level security](https://www.elastic.co/docs/deploy-manage/users-roles/cluster-or-deployment-auth/controlling-access-at-document-field-level): read the relevant limitations. Relevance can use global index statistics, including excluded documents. Returning only permitted documents doesn't imply all ranking side channels disappear.
- [LLMLingua](https://arxiv.org/abs/2310.05736) and [PDF](https://arxiv.org/pdf/2310.05736): abstract, small-model/controller/iterative-compression/distribution-alignment selections checked. Reported compression results are experimental and task dependent. Preserve original source spans separately; a compressed prompt isn't the original citation evidence.
- [TRUE](https://arxiv.org/abs/2204.04991): abstract and publication metadata checked. Its factual-consistency evaluation concerns example-level judgments across multiple datasets, not a proof that a verifier is infallible.
- [FActScore](https://arxiv.org/abs/2305.14251): abstract and metadata checked. Atomic source-supported factual precision differs from whole-answer quality, and its automated estimator remains an estimator. Historical model scores weren't presented as current comparisons.
- [RAGAS](https://arxiv.org/abs/2309.15217): abstract and metadata checked. Qualified the article's reference-free claim as metrics described by the original paper; it isn't a description of every metric in the maintained toolkit.
- [OWASP 2026](https://genai.owasp.org/resource/owasp-genai-llm-top-10-2026/): reused the preceding same-day manual review's official release/document selections. Updated this article's general injection guidance citation to the current edition. Retrieved instructions don't acquire permission to reveal data or execute tools.
- Stable RAG, BM25, RRF, HyDE, ColBERT, Lost in the Middle, PagedAttention, and classical speculative-sampling mechanisms reuse the preceding manual reviews' primary selections. No new universal effectiveness, latency, compression, or benchmark claim is inferred from those studies.

## Removed generated prescriptions and scope

The generated packet prescribed 100-ms production search, 200-ms visible answers despite preceding work, fixed external-search latency and reranker pool sizes, universal k=60 effectiveness, context-position/compression recipes, unverifiable proprietary serving topology, and legacy vendor/model examples as current architecture. It also treated lexical/vector model categories loosely and model-derived entailment as proof. None of those prescriptions was retained as verified evidence.

Kept the article's concrete policy/exception problem, independent live-state routing, authorized evidence retrieval, negation counterexample, checked-claim publication, end-to-end critical path, distinct occupancy populations, and separate hypothetical workload worksheets. Its local vectors, decisions, prices, capacities, and arrival mix are fixtures, not learned models, current vendor quotations, or measured deployment results. Eight cells run on CPU; no provider call, live index, model-derived entailment test, distributed stream, GPU benchmark, or deployment was performed. Relevant upstream selections were read, not complete projects or every full paper.
