## Corrections and limits

Reproduced three bounded-score guards crashing on an oversized integer, an approved prohibited-signature match being demoted to review when an optional score was unavailable, and floating/boolean revision labels publishing through Python equality. The examples now reject unsupported scores through their specified error/review route, give trusted signature matches explicit precedence, and require integer revisions before mutating state. Inline regression cases retain the ordinary scenario arithmetic.

The sampler also crashed on an oversized numeric input and a finite-parameter product overflowing. It now rejects unsupported range with ValueError. Its luminance cuts remain a toy evidence-selection rule, not full video-policy coverage.

Removed the implication that wording changes must ship as configuration before classifier updates. Both candidates need policy-specific evidence and release approval. Added the distinction between credible experimental evidence and a favorable point estimate, and clarified that stopping publication doesn't authorize a model to delete or report content.

Removed unsupported generated claims about universal three-tier layouts, zero-cost edge filters, near-zero regex false positives, fixed latency/exit-rate/cost/F1 gains, checkpoint-independent model benchmarks, unverified current pricing/framework versions, mandatory continuous retraining, and revocation undoing exposure after optimistic publication. The article's rates, timings, thresholds, queue populations, and scores remain declared synthetic inputs or local arithmetic.

All source checks concern the selections described above. No complete upstream project, comprehensive legal status audit, provider/model call, media detector, human-review trial, GPU benchmark, or production enforcement/deployment was performed.
