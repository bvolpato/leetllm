# Recursive Language Models: manual source notes

Checked September 22, 2026. These notes replace the earlier draft packet, including its external image, guaranteed-coverage claim, and assertion that recursion eliminates context rot.

- [Paper v3, May 11, 2026](https://arxiv.org/html/2512.24601v3) defines external prompt state, programmatic sub-calls, and truncated observations. Section 3 distinguishes fixed answer-relevant information from tasks requiring per-record or pairwise processing. It does not prove constant-time lookup, universally quadratic token bills, or a guarantee of accurate exhaustive extraction.
- [The arXiv version history](https://arxiv.org/abs/2512.24601) confirms v3 is the latest revision as of this review. The HTML abstract and main text describe a median post-training improvement, while the abstract page uses average wording. The lesson attributes the 28.3% relative median to the main text rather than silently equating the statistics.
- [The authors' original blog](https://alexzhang13.github.io/blog/2025/rlm/) explains flexible input decomposition and the original FINAL / FINAL_VAR interface. Its early experiments used one recursion level. Later paper depths and today's library arguments aren't interchangeable with that interface. Adaptivity is an available strategy, not a universal quality advantage over a fixed pipeline.
- [Pinned author-maintained runtime](https://github.com/alexzhang13/rlm/tree/854e688fbba9d8f8989e3da9989812e4b6dfe270) is still the latest main revision on September 22. `core/rlm.py` defaults to local execution, `max_depth` 1, and 30 iterations. Reaching the depth cap falls back to a plain model completion. Iteration exhaustion makes an extra best-effort call; configured timeout, token, or budget limits instead raise typed exceptions. The response string alone isn't the stop reason.
- [Local REPL source](https://github.com/alexzhang13/rlm/blob/854e688fbba9d8f8989e3da9989812e4b6dfe270/rlm/environments/local_repl.py) captures answer content when `ready` is truthy and converts content to a string. Our stricter typed candidate example isn't this library's implementation. Child recursion can use host threads with separate variable namespaces; it returns strings, not whole child interpreter states. The context alias is restored, but source objects and backing files aren't a general immutable security barrier.
- [Budget and child execution source](https://github.com/alexzhang13/rlm/blob/854e688fbba9d8f8989e3da9989812e4b6dfe270/rlm/core/rlm.py) checks totals after iterations, checks elapsed time before another iteration, and passes remaining allowances to children without atomic reservation. Missing cost becomes zero in the budget check. Some child errors become error strings. These behaviors require application-level accounting, typed error handling, and independent executor limits.
- [Plain batch handler](https://github.com/alexzhang13/rlm/blob/854e688fbba9d8f8989e3da9989812e4b6dfe270/rlm/core/lm_handler.py) overlaps separate completions with an async semaphore. Local recursive batches use a per-parent thread pool. Neither combines all prompts into one billed request nor provides a global tree-wide concurrency cap.
- [Paper Table 1](https://arxiv.org/html/2512.24601v3#S4) supports the selected historical scores and costs in the lesson. Window-limited base runs, distinct metrics, and differing sample sizes limit cross-row comparisons. Recursion can regress; these aren't current product quotes or proof of a universal Pareto improvement.
- [Paper Table 2 and Appendix A](https://arxiv.org/html/2512.24601v3) support the decomposition-hint comparison, root-turn SFT recipe, trajectory filtering, and specific MRCRv2 length-generalization experiment. Those results don't guarantee arbitrary-length inference, full coverage, or production isolation safety.
- [FlashAttention](https://arxiv.org/html/2205.14135) retains quadratic dense-attention computation while reducing memory traffic and avoiding quadratic extra storage. Distinguish whole-prompt computation from cached per-token decoding; attention complexity alone doesn't prove a long-context accuracy mechanism.

Manual teaching repairs: include all pair merges in the recursive binary baseline; distinguish 85 run nodes from a 715-call expansion limit; show both preview histories growing with return count; keep character accounting explicit and exclude wrappers; show genuine REPL prompt slicing, atomic sub-call slot fan-out, and NumPy result aggregation; compare routing designs on the same tasks cleanly. A rejected recursive candidate isn't a whole-system hold while another candidate qualifies.

Evidence limits: code examples use compact corpus slices, fixed controller scripts, labeled records, and NumPy arrays so learners can run them offline without model API keys or containers. Native figures and both themes are verified separately. Relevant source passages and code paths were inspected directly.
