# Production-agent capstone: manual source notes

Checked September 22, 2026. The generated outline mixed unsupported timing guarantees, secondary-source recommendations, and incorrect persistence/resume claims. This lab is a deterministic planner and fixture services with real local SQLite records, not a production agent deployment.

- [AgentDojo](https://arxiv.org/abs/2406.13352) evaluates tool-use agents over untrusted data and adaptive prompt-injection attacks. Its abstract supports the threat, not a universal claim that an intake classifier eliminates it or meets a latency target.
- [OWASP Excessive Agency](https://genai.owasp.org/llmrisk/llm062025-excessive-agency/) separates excessive functionality, permissions, and autonomy. Runtime allowlists, downstream authorization, and high-impact review address particular capabilities. A system prompt or natural-language “passive evidence” label isn't enforcement.
- [ReAct](https://arxiv.org/abs/2210.03629) interleaves reasoning traces and actions. The fixture uses observations to select structured actions deterministically; it doesn't execute a reasoning model or measure its success rate.
- [LangGraph checkpointers](https://docs.langchain.com/oss/python/langgraph/checkpointers) persist graph state under thread identities. [Interrupts](https://docs.langchain.com/oss/python/langgraph/interrupts) restart the interrupted node on resume. They don't require cryptographic IDs, compute termination, or exact instruction-pointer restoration. This module implements a separate packet workflow without LangGraph.
- [SQLite transactions](https://www.sqlite.org/lang_transaction.html) permit multiple readers but one simultaneous write transaction per database. BEGIN IMMEDIATE starts a write transaction and can fail with SQLITE_BUSY. Closing a database rolls back its pending explicit transaction; removing a Python rollback call alone doesn't establish orphan committed writes.
- [Python sqlite3](https://docs.python.org/3/library/sqlite3.html) documents legacy isolation_level=None with explicit SQL transaction control. contextlib.closing closes this module's connections. Exception rollback, normal process exit, abrupt process loss, and power-loss durability are different experiments.
- [AWS idempotent APIs](https://aws.amazon.com/builders-library/making-retries-safe-with-idempotent-APIs/) discusses caller request identity, atomic server-side effects, changed-parameter rejection, and finite retention. Local SQLite uniqueness can't deduplicate a remote API effect, and a new retry key can create a second intent.
- [gVisor](https://gvisor.dev/docs/) is a userspace application kernel for sandboxed containers, not a microVM. Deep copying planner input isn't execution containment; neither gVisor nor another sandbox runs here.
- [AgentBench](https://arxiv.org/abs/2308.03688) evaluates interactive agents across eight environments. [Tau-bench](https://arxiv.org/abs/2406.12045) grades final database state and repeated-trial reliability. End-state tests don't themselves require a preferred action order or establish trace safety.

Manual implementation corrections: version 4 records an approval digest over the complete persisted packet, including expiration, inside a write transaction. Execution checks that digest and the current fixture question. The stable operation ID excludes expiration so restaging doesn't renew it. Existing version 3 databases aren't migrated; the default filename is versioned. Digests check consistency, not administrator tamper resistance or human identity. The expiration-edit exercise is a regression check for the original omission.

The accounting exercise now handles arbitrarily large integer durations without float conversion and rejects a nonfinite aggregate of individually finite float durations. The mutation exercise commits before the injected error to demonstrate why rollback can't remove a committed effect. Its separate rollback probe covers a boundary that the six-episode evaluator doesn't exercise.

Evidence limits: version strings and submitted trace summaries don't authenticate provenance. The local evaluator supplies known fixture observations and a fixture-suite result, not live release authority. No LLM, semantic retrieval model, safety classifier, external identity service, remote write, sandbox, power-loss experiment, in-flight budget enforcement, or deployment was run. No sub-50-ms latency or general injection-defense rate is established.
