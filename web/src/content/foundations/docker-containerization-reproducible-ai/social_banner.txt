Local Vizmatic artwork. Reproducible source: social_banner.tsx.
From the repository's web/ directory, render the 1200x630 PNG at scale 1:

pnpm exec tsx -e "import { renderBanner } from './src/content/foundations/docker-containerization-reproducible-ai/social_banner.tsx'; renderBanner('./src/content/foundations/docker-containerization-reproducible-ai/social_banner.png').then(console.log)"

The diagram separates the reusable access-rag:local image from a container running the scorer as appuser. Host eval data enters through a read-only runtime bind mount at /app/eval. The --rm option removes the exited container, not the image. No external image service or upload is required.
